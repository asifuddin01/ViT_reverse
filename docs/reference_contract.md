## Observed environment and architecture

The first architecture inventory ran with Python 3.12, PyTorch 2.14.1, torchvision 0.29.1, and timm 1.0.30 on macOS/arm64. `torch.backends.mps.is_available()` returned `False`; CPU is the current verification device. The installed source was inspected at `.venv/lib/python3.12/site-packages/timm/models/vision_transformer.py` and `timm/layers/attention.py`.

| Item | Observed value |
|---|---|
| Architecture | `vit_base_patch16_224` |
| Parameters | 86,567,656 |
| Image / patch / token shapes | `[1,3,224,224]` / `[1,196,768]` / `[1,197,768]` |
| Output | `[1,1000]` logits |
| Blocks / heads | 12 / 12 |
| Class token and pooling | one CLS token; `global_pool='token'` |
| Pre-block normalization | `Identity` |
| Final normalization | `LayerNorm` before CLS pooling, `eps=1e-6` in the first block |
| QKV | packed linear projection with bias; first-block weight `[2304,768]` |
| Attention dropout / drop path | `0.0` / `Identity` in the first block |
| Attention implementation | fused attention enabled by default in the inspected model |

The downloaded model config specifies 224×224 RGB input, bicubic interpolation, center crop with crop fraction 0.9, and mean/std each `(0.5, 0.5, 0.5)`. Do not substitute generic ImageNet normalization. The installed `Block.forward` is pre-norm: attention on `norm1(x)` is added to `x`, then MLP on `norm2(x)` is added to that result. `forward_features` applies patch projection, positional embedding, blocks, and final norm; `forward_head` pools the CLS token and applies the classifier.
